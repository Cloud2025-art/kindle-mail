# Reporting a security issue

Do not disclose passwords, private notes, vault settings or secret-storage contents in a public issue. Use a private vulnerability report through GitHub when enabled. If no private channel is available, open a minimal issue asking the maintainer for a private reporting channel without publishing exploit details or sensitive data.

If an SMTP app password is exposed, revoke it with the email provider and create a replacement. Removing the secret locally does not revoke a provider credential.
